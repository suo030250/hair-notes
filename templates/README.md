# 模板

| [來源](source.md) | `wiki/sources/` | 一份來源的摘要與限制 |
| [知識頁](knowledge-page.md) | `wiki/topics/`、`entities/` 或 `syntheses/` | 主題、實體或跨來源分析 |

| [Reels 企劃](reel-brief.md) | `projects/reels/專案名稱/brief.md` | 腳本、分鏡與素材規劃 |
