# Reels 專案入口

一支影片或一個系列建立一個專案資料夾，例如 `first-hair-reel/`。目前沒有已製作或已發布影片。

1. 複製 [企劃模板](../../templates/reel-brief.md) 為專案內的 `brief.md`。
2. 視需要加入 `assets/`、`script.md` 與成品；素材記錄來源與權利。
3. 複製 [實驗模板](../../templates/experiment.md) 為 `experiment.md`，先填假設，觀測後再填數據。
4. 在本頁加上專案連結，並在 [日誌](../../wiki/log.md) 留下 create 紀錄。

知識來源從 [Wiki 索引](../../wiki/index.md) 查找；流程參考 [從美髮知識到 Reels](../../wiki/syntheses/hair-to-reels.md)。
